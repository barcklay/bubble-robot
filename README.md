# Bubble Robot — Flying Companion MVP

Дрон-компаньон, который держится рядом с человеком на безопасной дистанции («bubble»):
на выбранной стороне, в кольце 1.5–2 м, медленно и ниже головы.

Сейчас в репозитории — программная часть, которая работает без железа: safety envelope,
state machine, планировщик и симулятор. План по майлстоунам — в Linear, проект
«Bubble Robot — Flying Companion MVP».

## Запуск

```bash
./run
```

Первый запуск сам создаёт `.venv` и ставит зависимости (нужен Python 3.11–3.13),
затем открывает симулятор.

| Команда | Что делает |
| --- | --- |
| `./run` | симулятор, человек управляется с клавиатуры |
| `./run sim --scenario` | тот же симулятор, но человек ходит по сценарию |
| `./run sim --headless` | 5-минутный сценарий без окна, за пару секунд; код возврата 1, если были нарушения |
| `./run test` | тесты |
| `./run make-tag --id 0` | PNG с меткой AprilTag 36h11 для печати |
| `./run apriltag --tag-size 0.16` | проверка AprilTag-трекинга на камере Mac |

### Клавиши в симуляторе

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | двигать человека |
| Space | взлёт |
| H | Hold, повторно — Resume |
| L | посадка |
| E | EMERGENCY STOP |
| R | сброс после аварийной остановки |
| T | выключить/включить трекер (проверка Hold → Land) |
| Esc | выход |

### Геймпад

Симулятор подхватывает геймпад сам, в том числе подключённый уже после запуска.
Раскладка рассчитана на Nintendo Switch Pro Controller, кнопки — по надписям на них.
Подключать лучше кабелем USB-C: для аварийной кнопки провод надёжнее Bluetooth.

| Кнопка | Действие |
| --- | --- |
| левый стик | двигать человека |
| A | взлёт |
| Y | Hold, повторно — Resume |
| B | посадка |
| L или R | EMERGENCY STOP |
| + | сброс после аварийной остановки |
| − | выключить/включить трекер |

Если геймпад отключился в полёте, дрон садится. Клавиатура продолжает работать всегда.

На экране: белый круг — человек (чёрточка показывает, куда он смотрит), красная
окружность — запретные 1.5 м, зелёное кольцо — рабочая зона 1.5–2 м, жёлтый крест —
цель, цветная точка — дрон (цвет = режим).

## Как устроено

```
bubble_robot/
  config.py              загрузка и проверка config.yaml
  safety/state_machine   DISARMED → TAKEOFF → ORBIT ⇄ HOLD → LAND, EMERGENCY_STOP
  safety/envelope        ограничитель setpoints и монитор нарушений
  control/planner        цель на кольце вокруг человека, обход по дуге
  tracking/              формат данных трекера, симулированный трекер, AprilTag на камере
  drone/simulated        симулированный дрон
  sim/                   мир симуляции и демо-сценарий
  ui/sim_app             окно симулятора (pygame)
  logs.py                запись прогона
config.yaml              все числа, включая safety envelope
docs/safety.md           правила испытаний
tests/
```

Один такт управления (50 Гц): трекер → state machine решает режим → планировщик
предлагает скорость → ограничитель режет её по скорости, ускорению, геозоне и высоте →
дрон. Симуляция и будущий реальный полёт отличаются только трекером и дроном.

## Safety

Ограничения первой версии заданы в `config.yaml`, раздел `safety`; небезопасные
сочетания (например, кольцо ближе минимальной дистанции) конфиг не загрузит.
Правила испытаний и условия немедленной остановки — в [docs/safety.md](docs/safety.md).

## Логи

Каждый прогон пишет в `logs/` два файла:

- `run-<дата>.csv` — телеметрия на каждом такте: положение человека и дрона, цель,
  дистанция, скорость, режим, возраст трекинга, заряд, нарушения;
- `run-<дата>.events.jsonl` — переходы state machine, отклонённые команды, начало
  каждого нарушения.

## Проверка AprilTag на камере Mac (HW-85)

1. `./run make-tag --id 0` → распечатать `apriltag.png`, измерить линейкой сторону
   чёрного квадрата.
2. `./run apriltag --tag-size <сторона в метрах>` — macOS спросит доступ к камере.
3. Отходить и поворачивать метку, пока трекинг не потеряется; Q — закончить.

В конце печатается средний FPS, максимальная дистанция и наклон с детекцией и условия
каждой потери; покадровый лог — в `logs/apriltag-<дата>.csv`. Дистанция считается из
угла обзора камеры (`--hfov`, по умолчанию 70°), без калибровки — сверить с рулеткой.
